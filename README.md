# Git Practice Playground

Follow the exercises in this workspace to learn practical Git workflows.

Files:
- [exercises.md](exercises.md) — step-by-step tasks to try.
- [solutions.md](solutions.md) — reference commands and answers.
- [hello.py](hello.py) — small sample script.
- [feature.txt](feature.txt) — file used for merge/conflict exercises.
- [.gitignore](.gitignore) — recommended ignores.

Quick start
1. Open a terminal in this folder.
2. Initialize a repo: `git init`.
3. Follow exercises in [exercises.md](exercises.md).

Check your history often with:
```
git log --oneline --graph --all
```
